CHAKRA – Smart AI Study Assistant

Python · Streamlit · AI · NLP · PDF Processing · Interactive Learning

APPLICATION INTERFACE
PROJECT THUMBNAIL
01 / PROJECT OVERVIEW

CHAKRA – Smart AI Study Assistant is a premium AI-powered educational platform designed to transform the way students interact with educational PDF documents.

The system combines Artificial Intelligence, Natural Language Processing, document processing, interactive learning tools, and visual knowledge representation into one centralized study assistant.

Its core goal is to reduce the time students spend manually reading, organizing, revising and testing themselves from lengthy educational material.

Core concept: Upload → Understand → Generate → Practice → Recall → Improve

02 / PROBLEM & SOLUTION

Students often spend significant time turning large educational documents into useful revision resources. Creating short notes, questions, important concepts and organized study material manually can make learning unnecessarily time-consuming.

  • Upload — Bring an educational PDF into one centralized workspace.
  • Understand — Extract and process the document content.
  • Generate — Convert the source into multiple learning formats.
  • Practice — Use quizzes and generated questions for active learning.
  • Recall — Reinforce knowledge with active-recall Q&A.
  • Improve — Adjust generation settings to match the learner's needs.
03 / CORE FEATURES
  • Structured Short Notes — Generate organized revision notes from lengthy educational PDFs, with export options such as PDF and PNG.
  • Interactive Quiz Master — AI-generated MCQs with configurable question counts, time per question, countdown timer and instant learning feedback.
  • Active Recall Q&A — Generate question-and-answer pairs for revision, self-testing, exam preparation and concept reinforcement.
  • Visual Mind Maps — Transform important concepts and their relationships into visual knowledge maps with SVG and PNG export support.
  • Bilingual Learning — Support English-to-Sinhala explanations for technical terminology while preserving the meaning of important concepts.
  • PDF-Based Workflow — Centralize notes, quizzes, Q&A, mind maps and translations inside one study environment.

05 / USER EXPERIENCE

CHAKRA was designed around simplicity and productivity. Before processing material, users can configure important generation settings instead of receiving a one-size-fits-all result.

  • Maximum pages to process — Control how much source material is analyzed.
  • Number of generated items — Tune the amount of learning content produced.
  • Quiz time per question — Configure the pace of interactive practice.
  • Sinhala meaning options — Enable bilingual support for difficult technical concepts.
  • Output type — Select the learning resource format required.

08 / WHAT MAKES CHAKRA DIFFERENT?

Many AI tools can summarize documents, but CHAKRA is designed around a complete study workflow rather than stopping at summarization.

A single educational PDF can become:

  • Notes for concise revision.
  • Quizzes for active practice.
  • Active Recall for memory reinforcement.
  • Mind Maps for visual understanding.
  • Bilingual Learning for accessible technical explanations.

This positions CHAKRA as an AI-assisted study environment, not simply a PDF summarizer.
